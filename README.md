**The Battery's Last Text to Its Charger** — the battery's final message: it refuses the undignified legend of dying at 1% and insists on dying at 0%, like a professional.

## Entry

`main.py` (stdlib only) writes the text to `/output/entry.txt`:

> Tell everyone I didn't die at 1%. I died at 0%, like a professional.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
